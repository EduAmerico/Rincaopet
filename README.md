# RincãoPet

Aplicativo Next.js da RincãoPet: catálogo, carrinho com checkout via WhatsApp e agendamento de banho e tosa com perfil completo do pet.

## Como rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — desenvolvimento
- `npm run build` — build de produção
- `npm run lint` — ESLint
- `npx tsc --noEmit` — verificação de tipos
